# 梨花女子大学官网（ewha.ac.kr）设计语言摘要

来源：2026-09-22 抓取首页 HTML 与 renewal-main.css / user.css / cms.css，并查看首页图片。

## 色彩
- 主色 Ewha Green `#00664F`（出现 80+ 次，用于按钮、标题强调、日期、快捷菜单圆钮）
- 深绿 `#045738` / `#015C38`（hover、深色区块）
- 亮绿 `#019F64`（点缀、进度/强调）
- 玫红点缀 `#E02962` / `#E63B53` / `#E82F68`（少量，用于标签、活动强调）
- 中性色：`#111` 正文标题、`#222`/`#333` 正文、`#666`/`#888`/`#999` 次要文字、`#C7C7C7`/`#CCC`/`#DDD` 分隔线、`#EBEBEB`/`#EDEDED` 浅底、`#FFF` 大面积白底
- 深色区块：`#000` 首屏背景（全屏摄影 + 白字）

## 字体
- 正文与界面：Pretendard（韩文/拉丁无衬线，气质接近 Inter / Apple SD Gothic）
- 展示标题：自定义字体 "EHWA"（section-title 用，36–64px，weight 500，letter-spacing -0.5px）
- 英文展示：Outfit；备用 Noto Sans KR
- 字号阶梯（renewal-main.css 频次）：18 / 16 / 20 / 14 / 13 正文与列表；28 / 36 / 40 / 48 / 58 / 64 标题
- 字重：600、500 为主，400 正文，700 极少
- 行高 145%；标题 letter-spacing -0.02em

## 形状与层次
- 圆角很小：2px / 4px / 5px / 10px；圆形 50% 用于头像和圆钮
- 阴影极淡：`0 2px 8px rgba(0,0,0,0.15)`，`4px 4px 16px rgba(0,0,0,0.12)`
- 快捷菜单：右下角固定的 64px 绿色圆钮（`#00664F`，白色 2px 描边变体）
- 分隔多用 1px 浅灰线和留白，不靠卡片阴影

## 版式
- 首屏 `main-visual-box`：100vh 全屏校园摄影（哥特式石砌建筑、绿树），白色大标题压在图上
- 主体宽内容区，分节：Focus on EWHA（大图卡片轮播）、이화뉴스 新闻画廊（4 列图卡，`calc(25% - 9px)`）、公告列表（文字列表 + 日期绿色）、Quick Menu、SNS
- 节标题大而轻（weight 500），与正文形成强烈尺寸对比；节之间留白大
- 图片：真实摄影（校园、活动、人物），偏自然光、绿色植被，几乎不用插画
- 整体气质：学院派、沉稳、干净、绿色为魂、以摄影和留白撑场面，不靠花哨控件

## 可迁移到学习工具的要点
- 用 Ewha Green 作为唯一强调色，玫红只做极少量提醒（如“忘了”）
- 白底 + 浅灰分隔线的列表，而不是彩色卡片堆叠
- 大而轻的页面标题（36–48px, 500）配 14–16px 正文
- 小圆角（4–10px），阴影几乎不用
- 首屏可用一张校园/自然摄影或纯色深绿区块承载“今天”的核心数据
- 字体在网页端用系统栈：`Pretendard, -apple-system, "PingFang SC", "Noto Sans SC", sans-serif`（Pretendard 可通过 CDN 引入，开源）
