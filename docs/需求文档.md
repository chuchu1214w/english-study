# 英语自学网页 · 需求文档

> 版本 1.0 · 2026-09-21 · 通过两轮问答确认

## 1. 使用者画像

- 唯一用户：momo（本人使用，不考虑多用户）
- 目标：**雅思应试** + **在美生活的日常口语交流**
- 目标分数与考试日期：尚未确定，**做成可设置项**，计划按设置自动推算
- 学习时间：**不固定**，工作日和周末分别设定每日时长

## 2. 核心模块（四个，全部纳入 v1）

| 模块 | 需求要点 |
|---|---|
| 单词记忆 | 生词本；间隔重复（SM-2 变体，只有“记得 / 忘了”两档，越简单越容易坚持）；标签（雅思/日常/自定义）；批量导入；AI 一键补全释义、音标、雅思例句、美国日常用法 |
| 学习计划与打卡 | 目标分/考试日期/开始日期可设置；工作日与周末时长分别设定；按星期轮换专项（听/读/写/说）自动生成每日任务；每日勾选打卡；连续天数；周学习时长图 |
| 练习记录 | 记录听力/阅读/写作/口语每次练习的材料、时长、分数、错误、心得；写作与口语可请 AI 按雅思评分标准打分并反馈 |
| 错题本与语法笔记 | 错题/语法两类；标签检索；关键词搜索；AI 解释错因或语法点 |

## 3. 技术形态

- **纯静态网页**（HTML/CSS/原生 JS，无构建步骤），本地双击 index.html 即可用，也可部署 GitHub Pages
- 数据主存 **浏览器 localStorage**，并通过 **GitHub Contents API** 同步到**私有仓库** `english-study-data` 的 `data.json`
- 支持导出/导入 JSON 备份
- 仓库拆分：代码公开仓库 `english-study`（可上 Pages），学习数据私有仓库 `english-study-data`

## 4. AI 能力

- 提供方：**Claude（Anthropic）**，浏览器直连 API，不经任何中转服务器
- API Key 只保存在本机浏览器 localStorage，**绝不写入 data.json，绝不提交到 GitHub**
- 功能清单：单词补全、写作批改（雅思 Task 1/2 四项评分）、口语反馈、错题/语法讲解、口语话题与美国生活情景对话生成

## 5. 非功能需求

- 手机与电脑浏览器都能用（响应式）
- 无网络时仍可离线记录，联网后再同步
- 数据格式带版本号，便于后续迁移

## 6. 明确不做（v1）

- 账号系统、云端数据库
- 内置词库（用户自行录入或 AI 补全）
- 多设备实时协同（依赖手动/自动同步即可）
